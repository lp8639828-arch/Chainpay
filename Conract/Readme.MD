# ChainPay

## Project Description
**ChainPay** is a decentralized payment protocol built on the Ethereum blockchain.  
It enables users to **deposit**, **send**, and **withdraw** Ether securely without intermediaries.

---

## Project Vision
To create a **trustless, transparent, and efficient** payment system that empowers users to manage their digital assets directly on-chain.

---

## Key Features
- 💰 **Deposit ETH**: Users can securely store their funds in the smart contract.
- 🔄 **Send Payments**: Instantly transfer ETH to other users on the network.
- 🏧 **Withdraw Funds**: Withdraw your ETH anytime, directly to your wallet.
- 🔒 **Secure & Transparent**: Powered by blockchain and verified by smart contracts.

---

## Future Scope
- 🚀 Integration with ERC-20 tokens for multi-currency support.
- 📱 Development of a front-end dApp for seamless user experience.
- 🔐 Advanced security features (multi-signature, transaction limits).
- 💳 Integration with off-chain payment gateways for hybrid systems.
