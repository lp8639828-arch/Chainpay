# 💸 ChainPay

## 📖 Project Description
ChainPay is a decentralized payment platform built on Ethereum using Solidity.  
It enables users to **send and receive payments securely without intermediaries** — a simple, transparent, and trustless payment mechanism powered by blockchain.

---

## 🌍 Project Vision
To create a **secure and transparent decentralized payment solution** that empowers individuals and businesses to make peer-to-peer transactions instantly, anywhere in the world, without depending on banks or third-party platforms.

---

## 🚀 Key Features
- **Instant Payments:** Send ETH directly to any address on the blockchain.
- **Secure Transactions:** Every payment is recorded permanently on the Ethereum blockchain.
